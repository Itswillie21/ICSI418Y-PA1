## Description of Product
This product is a web application in which the user may create a list of tasks to be accomplished, a to do list if you will. Users may rank tasks based on 3 levels of priority, as well as track and delete completed tasks.

## Instructions to Run Program
1.) Download or cone repository
2.) Start "index.html" in a browser
3.) Enter a task(s) and their corresponding level of urgency
4.) Click "Add Task"
5.) Remove task once completed, or when tracking is no longer desired

## Program Features
- Add a task(s)
- Set level of urgency
- Mark completion of tasks
- Delete completed tasks
- View completed tasks
- Reject addition of empty task
